# McL Stick War

Estrategia en tiempo real de lado a lado para el navegador, al estilo de Stick War, en 3D. Los mineros traen oro. Con él entrenas espadachines, arqueros, lanceros, magos y gigantes, y les das órdenes (refugio, defender o atacar) para derribar la estatua enemiga.

- Los niveles no se acaban: cada uno tiene un enemigo más fuerte y desbloquea unidades nuevas.
- Las unidades son avatares 3D como los del Arcade, y las tuyas llevan tu personaje.
- Hay 4 dificultades, pantalla completa por defecto y modo oscuro AMOLED (cielo negro con estrellas).

## Ejecutar

```sh
npm install
npm run dev      # /?demo&nivel=4 empieza una partida directamente
npm test
npm run build
```
